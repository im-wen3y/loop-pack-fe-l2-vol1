# 6주차 체크리스트

> 기준: [`docs/assignments/week-06.md`](../assignments/week-06.md)
> 점검일 기준 실제 코드·런타임 대조 결과. 설계 판단과 근거는 [`docs/rfc/week06-fsd.md`](../rfc/week06-fsd.md)에 기록.

**0단계 — 동작 기준선**

- [ ] 홈과 상품 목록의 정상·로딩·에러·빈 상태를 이동 전에 확인했는가
- [ ] 검색·카테고리·정렬·페이지네이션을 이동 전에 확인했는가
- [ ] URL 공유·새로고침·뒤로/앞으로 가기를 이동 전에 확인했는가
- [ ] 장바구니·위시리스트 동기화와 페이지 이동 중 헤더 개수 유지를 확인했는가
- [ ] 이동 전 `pnpm check`가 통과했는가
- [ ] 리팩토링 중 발견한 기존 버그를 구조 변경과 다른 커밋으로 분리했는가

**1단계 — RADIO + RFC**

- [ ] 파일을 옮기기 전에 RFC를 커밋했는가
- [ ] R — 보존할 동작과 이번 주에 하지 않을 것을 적었는가
- [ ] A — 현재 구조에서 겪는 문제를 3개 이상 적었는가
- [ ] A — Before/After 폴더 트리와 허용·금지 import 예시를 적었는가
- [ ] A — 파일 매핑표를 작성했는가
- [ ] A — 애매한 파일 5개 이상을 후보 비교 후 근거로 결정했는가
- [ ] D — 상태 분류표를 새 구조에 맞게 갱신했는가
- [ ] I — 각 슬라이스가 공개할 값과 숨길 구현 세부를 정했는가
- [ ] O — 캐시 정책, 로딩·에러 경계 범위, 하지 않을 최적화를 적었는가

**2단계 — FSD 전환**

- [ ] 상위→하위 방향의 import만 있는가
- [ ] 같은 레이어의 다른 슬라이스를 직접 import하지 않는가
- [ ] `entities → features` 역방향 import가 없는가
- [ ] `ProductCard`와 장바구니·위시리스트 행위를 widget 또는 page에서 조합했는가
- [ ] 필요한 레이어·세그먼트만 만들었는가 (빈 폴더·미사용 `index.ts` 없음)
- [ ] 세그먼트 이름이 파일 종류가 아니라 목적을 드러내는가
- [ ] `src/pages`를 만들지 않고 `src/_pages`를 사용했는가
- [ ] `src/app/**`의 진입점을 얇게 유지했는가
- [ ] 서버·URL·클라이언트 상태의 Source of Truth가 이동 전과 같은가
- [ ] 같은 데이터를 여러 저장소에 복사하지 않았는가

**3단계 — Public API**

- [ ] barrel file과 Public API의 차이를 설명할 수 있는가
- [ ] 사용/미사용을 결정하고 그 의도를 RFC에 기록했는가

**4단계 — 에러 처리 경계**

- [ ] 에러 처리 표를 작성했는가
- [ ] `throwOnError` 기준이 표의 `전파하는가` 열과 일치하는가
- [ ] 조회 실패가 나머지 화면을 가리지 않고 전체 새로고침 없이 재시도되는가
- [ ] 적절한 route segment에 `error.tsx`와 `reset`을 두었는가
- [ ] 공통 에러 타입을 쓴다면 네트워크·HTTP·비즈니스 오류를 구분했는가
- [ ] `shared`에 특정 화면의 문구·행위를 넣지 않았는가
- [ ] 이벤트 핸들러·비동기 콜백 오류의 처리 위치를 기록했는가
- [ ] `loading.tsx`/Suspense와 Query `isPending`의 담당 범위를 구분했는가
- [ ] 검증용 임시 `throw`를 제거했는가
- [ ] `scenario`를 사용자 URL 상태나 `ProductListQuery`에 넣지 않았는가

**5단계 — 삭제 시나리오 자가 검증**

- [ ] 위시리스트 제거 시 삭제할 파일·수정할 파일을 예측했는가
- [ ] 삭제 대상이 한 곳에 응집되어 있는가
- [ ] 신상품 뱃지 추가 시 터치할 파일을 예측했는가
- [ ] 발견한 파편화에 대해 이번 주에 고칠 것과 남길 것을 근거와 함께 정했는가

**Advanced를 선택한 경우에만** (선택: A 의존성 하네스, B 변경 반경 실험)

- [ ] 기본 과제를 먼저 완성했는가
- [ ] 선택한 항목과 선택 이유를 기록했는가
- [ ] 추가한 복잡도와 검증 결과를 설명할 수 있는가
- [ ] A 선택 시 최소 두 규칙을 자동 검증했는가
- [ ] B 선택 시 구현 전 예상과 실제 diff를 비교했는가

**공통**

- [ ] 이동 후에도 기준선의 동작이 그대로인가
- [ ] FSD 이해 확인 질문 6개에 답했는가

# PR 디스크립션 작성

TRIGGER — PR 디스크립션 작성, PR 본문 작성 요청 시 이 스킬을 먼저 로드.

## 템플릿

`.github/pull_request_template.md`를 반드시 따른다.

## 자동 수집 (사용자 입력 불필요)

아래 항목은 git 정보에서 자동으로 추출한다:

- **주차**: 브랜치명에서 추출 (예: `feat/week-01-...` → `Week 01`)
- **무엇을 / 왜**: `git log main..HEAD`와 `git diff main...HEAD --stat` 기반으로 초안 작성, 사용자 확인 후 확정
- **AI 생성 범위**: 본문 끝에 자동 추가

## ✅ 선행 조건

PR 디스크립션을 작성하기 전에 아래 3가지를 **반드시 완료**해야 한다:

1. **`self-review` 스킬** — 전체 diff를 6단계 + 문서-코드 동기화 점검
2. **`component-review` 스킬과 대상 경로** — 수정된 컴포넌트/Hook의 관심사 분리·책임 점검
3. **[FSD 검증 규칙](../../../.claude/rules/fsd-verification.md) 검증** — 파일 배치·Public API·슬라이스 경계 확인

선행 조건을 완료하지 않으면, 이 스킬은 다음을 출력하고 진행하지 않는다:

```
아직 선행 조건을 완료하지 않았습니다.

완료 항목을 확인해주세요:
- [ ] self-review 스킬 (diff 6단계 + 문서-코드 동기화)
- [ ] component-review 스킬과 대상 경로 (관심사 분리·책임)
- [ ] FSD 검증 완료 (파일 배치·Public API·경계)

완료 후 다시 요청해주세요.
```

## 사용자 입력 필수

아래 항목은 사용자에게 반드시 질문하여 받는다:

1. **학습 주제**: 이번 과제를 통해 학습한 주제
2. **배운 것 / 새로 적용한 것**: 새로 배우거나 적용해 본 내용
3. **고민한 점 / 막혔던 부분**: 선택을 두고 고민한 것, 어려웠던 것, 미해결 사항
4. **피드백 받고 싶은 부분**: 리뷰어가 집중해서 봐줬으면 하는 부분

## 작성 절차

1. **선행 조건 확인** — 위 3가지 완료 여부를 확인 (미완료면 중단)
2. `git log`, `git diff --stat`으로 변경 사항 파악
3. 사용자에게 필수 입력 4가지 질문
4. 템플릿에 맞춰 디스크립션 조합
5. 본문 끝에 AI 생성 범위 한 줄 추가 (예: "AI: Claude Code로 초안 작성 후 수동 편집")
